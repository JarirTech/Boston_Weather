# Boston_Weather
# Boston Weather Dashboard

## Overview

The Boston Weather Dashboard is a responsive web application that displays weather information for Boston through an interactive and user-friendly interface. The project was built using HTML, CSS, and JavaScript to strengthen front-end development skills and demonstrate how weather information can be presented in an engaging dashboard.

The application includes weather-related visuals, temperature, wind, and rain information while emphasizing responsive design and an intuitive user experience.

---

## Features

- Responsive web interface
- Weather dashboard layout
- Display of weather conditions
- Temperature information
- Wind information
- Rain information
- Weather images and icons
- Interactive user interface
- Clean and organized page layout
